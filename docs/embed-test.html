Mia embed test page

This page exists to test that the floating chat bubble loads and works from http://localhost:PORT. To run it: 

cd c:\rok\mia\docs
python -m http.server 8000
# then open http://localhost:8000/embed-test.html

Sofía's allowedOrigins must include http://localhost:* for this to work. Direct visits to https://mia.agenciarok.es/dra-sofia-vazquez will show the “access restricted” page, because the Referer won't be in the allowlist.
